Claude supports custom MCP connectors. After your WhatsApp Connection is active, add Normal as a connector, complete OAuth, and choose the exact connections and permissions Claude can use.

## Connect Claude

1. In Claude, open Settings, then Connectors.
2. Add a custom connector using your Normal MCP server URL.
3. Complete sign in and explicitly select the WhatsApp Connections and requested permissions.
4. Enable the Normal tools in a new chat.

Begin with a bounded read request such as:

> Summarize today’s messages from the launch group.

## Does Claude receive every connection automatically?

No. Only the WhatsApp Connections explicitly selected during MCP Authorization are included. A WhatsApp Connection added later remains outside the grant.

You can revoke the MCP Authorization whenever you no longer want Claude to have access.

If you want complete removal, use the [ChatGPT and Claude removal guide](/guides/remove-normal-from-chatgpt-and-claude) so you both remove Normal in Claude and revoke its MCP Authorization in Normal.
