# Split the Vercel web app and Cloudflare API in one monorepo

The provider module was later renamed to `packages/whatsapp-provider`; the
original path below is historical.

Use one Bun-workspace monorepo with an independently deployed Next.js web app on Vercel, a native Cloudflare API Worker data plane, and a private provider-control Worker reachable only through a service binding. The initial layout is `apps/web`, `apps/api`, and `apps/provider-control`, plus `packages/domain` for pure rules, `packages/contracts` for product and MCP schemas, `packages/db` for migrations and tenant repositories, and `packages/wasender` for separately exported session/control clients and webhook normalization. Later ADRs added `apps/docs`, the deletion and restore coordinators, `apps/operations-control`, and the recovery-control, recovery-verifier, and recovery-game-day Workers without changing this split. Encryption orchestration and use cases stay in the API app until proven reusable. Turborepo provides dependency-aware builds, type checks, tests, linting, and cacheable CI tasks; migrations and deployments remain explicit non-cached side effects. The API Worker owns MCP and OAuth endpoints, product APIs, Wasender webhooks, asynchronous ingestion, per-session operations, and message decryption; the provider-control Worker alone holds the account-level Wasender PAT for create, connect, QR, and delete operations and cannot read message content. The web app owns the signed-in product UI. Browser calls use short-lived Clerk JWTs bound to the exact API audience, with strict issuer, audience, authorized-party, expiry, Origin, account, and object authorization at the Worker; the Next.js server does not proxy data-plane calls or receive provider credentials, data keys, or decrypted message content. This split adds cross-platform deployment and observability work, but isolates public ingestion, AI tool traffic, and full-account provider authority while allowing database, authorization, and provider contracts to evolve atomically in one repository.
