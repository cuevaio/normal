# Use authorization-bound keyset cursors

Return all `list_connections` results unpaginated, but paginate contacts, groups, and conversations with a default of 20 and maximum of 50 using deterministic keyset order. A short-lived HMAC cursor binds the MCP Authorization, tool, explicit connection handle, normalized filters or search, limit, sort version, last sort tuple, and expiry; any mismatch is an `invalid_cursor` execution error. REST Directory contacts and WhatsApp Conversations use a separate signing document that binds the API Key grant, stable operation ID, Connection, normalized filters, limit, sort version, boundary, and expiry; MCP and REST cursors are not interchangeable. Directory entries sort by normalized display name and handle, while conversations sort by Conversation Activity descending and handle. Responses include `next_cursor`, `has_more`, and projection freshness metadata. Traversal is intentionally not a persisted snapshot, so concurrent changes may move entries and clients can restart from the first page.
